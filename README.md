# alesierysuje.pl

Strona-serwis alesierysuje - live painting na weselach i eventach + portrety na zamowienie.

- Stack: React Router 7 (SSR), Payload CMS 3, Tailwind CSS, SQLite (dev) / PostgreSQL (prod)
- Wytyczne: CLAUDE.md
- Specyfikacja: docs/SPEC.md, design: docs/prototyp.html

## Komendy

- `npm run dev` - dev server
- `npm run build` - build produkcyjny
- `npm run typecheck` - sprawdzenie typow
